# ✅ Proyecto Final - Automatización de Pruebas con Cypress

Este repositorio contiene el Proyecto Final de la materia **Diseño e Implementación de Pruebas de Software**, desarrollado utilizando **Cypress** para la automatización de pruebas de Frontend y API.

## 📋 Descripción

El objetivo de este proyecto es documentar y automatizar casos de prueba aplicando los conocimientos adquiridos durante la cursada.

Se incluyen pruebas de:

* Frontend (FE)
* API
* Casos exitosos
* Casos de validación de errores

## 🚀 Instalación

Clonar el repositorio:

```bash
git clone [URL_DEL_REPOSITORIO]
```

Instalar dependencias:

```bash
npm install
```

## ▶️ Ejecutar las pruebas

Abrir Cypress:

```bash
npx cypress open
```

Ejecutar todas las pruebas:

```bash
npx cypress run
```

## 📌 Consideraciones

* El proyecto contiene los casos de prueba documentados y automatizados solicitados por la cátedra.
* Se aplican buenas prácticas de automatización para facilitar el mantenimiento y la reutilización del código.
* Todas las pruebas fueron desarrolladas utilizando Cypress.
